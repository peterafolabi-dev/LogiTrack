03 / Field guide

Clear docs. Faster dispatch.

A quick orientation for connecting a workspace and following shipment events.

01Quickstart+

Create a LogiTrack account, add a shipment from the dispatch console, then use its tracking ID to inspect status and shipment history.

02Webhook integration+

Save an HTTPS endpoint and select shipment event preferences in Workspace Settings → API & Webhooks. In this deployment, preferences are stored but event delivery is not configured.

03Carrier spec+

Choose the carrier or in-house fleet when creating a consignment. Carrier-specific live integrations and tracking sync are not enabled here; current statuses are managed in the shipment workspace.
